# java-lotto-8

## 입력

- [x]  모든 입력은 예외가 발생하면 발생 지점에서부터 재입력을 받게 한다.
- 로또 구입 금액 입력
    - [x]  Console.readLine()으로 입력 받기
    - [x]  1,000원으로 맞아 떨어지는지 확인, 맞아 떨어지지 않으면 예외
    - [x]  입력값이 숫자인지 확인, 아닐 시 예외
    - [x]  최소 1000원 이상 입력하도록 제한, 음수나 1000원 이하는 예외

- 당첨 번호 입력
    - [x]  숫자인지 확인, 아닐 시 예외
    - [x]  ,(쉼표)로 구분
    - [x]  당첨 번호는 반드시 6개, 그 외엔 예외
    - [x]  1 ~ 45 사이의 숫자여야만 함. 그 외는 예외

- 보너스 번호 입력
    - [x]  숫자인지 확인
    - [x]  1 ~ 45 사이의 숫자인지 확인
    - [x]  당첨 번호와 겹치진 않는지 확인

## 출력

- 로또 번호 출력
    - [x]  구입금액 / 1000 만큼의 로또 출력
    - [x]  로또 번호는 오름차순 출력

- 당첨 내역 출력
    - [x]  당첨 정보를 하나의 객체로 만들어 저장 (당첨 번호 + 보너스)
    - [x]  로또 한 장 당 당첨 정보와 몇 개 일치하는지 세기
    - [x]  일치 개수 + 보너스 여부로 등수 매핑

- 수익률 출력
    - [x]  소수점 둘째 자리에서 반올림해서 출력
